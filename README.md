# Workflow Manager (MERN Stack)

A full-stack Workflow Manager App built with the MERN stack (MongoDB, Express, React, Node.js).  
It allows users to register/login, manage their goals/tasks (CRUD), and persists data securely using JWT authentication.

---

## Features
- User authentication: Register and login with JWT tokens
- Goals/Tasks management: Create, Read, Update, Delete goals
- Protected routes: Only logged-in users can access the dashboard
- Frontend: React with clean UI
- Backend: RESTful API with Express and MongoDB
- Deployment ready (Render for backend + Netlify/Vercel for frontend)

---

## Tech Stack
- Frontend: React, Axios
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Authentication: JWT (JSON Web Tokens)
- Deployment: Render (backend) + Netlify/Vercel (frontend)
